# OpenCBT

Open-source Community Based Tourism (CBT) platform connecting local communities with responsible travelers — starting with a Sylhet, Bangladesh pilot (Jaflong, Khasia Punji, Rena, and the tea garden belt).

## Status
Phase 0–11 complete: docs/blueprint, UI foundation, Auth, Community Profile, Destination Explorer, Experience Marketplace, Homestay + Booking, Heritage Archive, Maps + GIS, Analytics + Sustainability Tracker, AI Assistant + Search, deployment prep. See `docs/CURRENT_STATUS.md` and `docs/DEPLOYMENT.md` to go live.

## Run Locally
```bash
npm install
npm run dev
```
